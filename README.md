# YORIAI

> **乗り合う。つながる。地域が動く。**

YORIAIは、地方における高齢者を中心とした「移動手段の不足」という課題を解決するために開発した、**地域密着型ライドシェアサービス**です。

地域の人がドライバーとなり、複数の利用者が車両を相乗りすることで、通常のタクシーよりも利用しやすい料金での移動を目指します。

単に「目的地まで移動する」だけではなく、移動を通して地域の人同士がつながり、外出・交流・消費・見守りなどにつながることで、地域全体を活性化させることを目標としています。

---

## 📌 開発背景

本サービスは、ハッカソン **HACK STAGE3** の「地方創生」というテーマをもとに企画・開発しました。

地方が抱える課題についてチームで検討する中で、高齢者を中心とした移動手段の減少に着目しました。

地方では、

- 公共交通機関の本数が少ない
- バス停や駅までの距離が遠い
- 自家用車への依存度が高い
- 免許返納後の移動手段が限られる
- 病院や買い物など、生活に必要な移動が難しい

といった課題があります。

そこで、地域住民がドライバーとして参加し、複数の利用者が同じ車両を利用することで、移動コストを抑えながら地域内の移動を支援するサービス **YORIAI** を考案しました。

---

# 💡 YORIAIが目指すもの

YORIAIでは、地方の移動問題を単純に「車を増やす」ことで解決するのではなく、

> **地域の人と移動手段を共有する**

という考え方で解決することを目指しています。

利用者は通常より最大20分程度乗車時間が長くなることを許容する代わりに、相乗りによって通常のタクシーよりも安価に移動できます。

また、地域の人がドライバーとして参加することで、移動手段の確保だけではなく、地域住民同士の交流や見守り、移住者と地域住民の接点づくりなどにつなげます。

---

# 🚕 サービスの特徴

## 1. 相乗りによる低価格な移動

通常のタクシーでは、基本的に利用者ごとに車両を利用します。

YORIAIでは、移動方向や時間帯の近い利用者同士が相乗りすることで、1台の車両を複数人で利用します。

利用者は、通常の移動時間から**最大20分程度長くなることを許容することで、より安い料金で移動できる**仕組みを想定しています。

料金は距離を基準として設定し、相乗りを行った場合にはさらに料金を抑える設計です。

これにより、通院や買い物などで定期的に移動する利用者の経済的負担を軽減します。

---

## 2. 地域密着型のドライバー

YORIAIでは、地域の人がドライバーとして参加することを想定しています。

ただし、安全性を確保するため、誰でもすぐにドライバーとして活動できる仕組みではありません。

ドライバー登録時には、

- 基本情報の登録
- 運転免許証の提出
- 必要書類の確認
- 運営側による審査

を行い、承認されたユーザーのみがドライバーとして活動できる設計です。

地域をよく知る人が地域の移動を支えることで、地域密着型の交通サービスを目指します。

---

## 3. 事前予約による配車

利用者は、

- 乗車地
- 目的地
- 希望到着時間

などを指定して事前に乗車予約を行います。

希望到着時間をもとに出発時間を調整し、条件の近い利用者がいる場合には相乗りを行うことを想定しています。

事前に予約を行うことで、利用者だけでなくドライバー側も運行予定を把握しやすくなります。

---

## 4. 高齢者でも利用しやすいUI

メインターゲットの一つとして高齢者を想定しているため、スマートフォン操作に慣れていない利用者でも操作しやすいUIを意識しました。

- 大きなボタン
- シンプルな画面構成
- 操作内容が分かりやすい文章
- 必要な情報を絞った表示
- スマートフォンを前提としたレイアウト

などを意識して設計しています。

# 🌱 YORIAIを利用するメリット

YORIAIが目指しているのは、単に「安く移動できるサービス」ではありません。

相乗りと地域住民の力を活用することで、

**利用者・ドライバー・移住者・地域それぞれにメリットが生まれる仕組み**

を目指しています。

---

## 👴 利用者にとってのメリット

### タクシーよりも移動費を抑えられる

地方では、自家用車を利用できない人にとってタクシーが重要な移動手段になる場合があります。

しかし、通院や買い物などで継続的にタクシーを利用すると、移動費の負担が大きくなります。

YORIAIでは、同じ方向へ移動する利用者同士が相乗りすることで、1台の車両を複数人で利用します。

利用者は乗車時間が最大20分程度長くなる代わりに、通常のタクシーより安い料金で移動できる仕組みを目指しています。

---

### 免許返納後も移動できる地域へ

地方では、自家用車が生活に欠かせない地域もあります。

そのため、

> 「免許を返納すると生活できなくなる」

という移動手段への不安が、免許返納を考える際の課題の一つになります。

YORIAIでは、

- 病院
- スーパー
- 市役所
- 駅
- 地域施設

など、日常生活に必要な場所への移動手段を地域の中で確保することを目指しています。

YORIAIは免許返納そのものを促すサービスではなく、

**「返納しても移動に困らない」という選択肢を増やすこと**

を目指しています。

---

### 希望到着時間を基準に予約できる

病院などへ行く場合、

「何時に出発するか」

よりも、

「何時までに到着したいか」

が重要になります。

YORIAIでは希望到着時間を指定し、それをもとに出発時間を調整する仕組みを想定しています。

利用者自身が複雑な移動時間を計算する負担を減らします。

---

# 🚗 ドライバーにとってのメリット

## 地域に貢献できる

地域住民自身がドライバーとして参加することで、普段暮らしている地域の移動問題を地域の中から支えることができます。

単なる仕事として運転するだけではなく、

> **地域の人の生活を支える**

という形で地域に関わることができます。

---

## 予定に合わせて活動できる

YORIAIでは、ドライバー自身が運行可能日を登録します。

利用者の予約とドライバーのシフトを組み合わせることで、事前に運行予定を確認できる仕組みを想定しています。

突然依頼を受けるのではなく、自分の予定に合わせて地域の移動を支えることができます。

---

# 🏡 移住者にとってのメリット

## 地域になじむきっかけをつくる

地方創生では、人を地方へ呼び込むだけではなく、

**移住した人がその地域で人間関係を築き、地域の一員として生活できる環境**

も重要だと考えています。

都市部から地方へ移住した人にとって、すでに形成されている地域コミュニティへ入ることは簡単ではない場合があります。

YORIAIでは、移住者がドライバーとして活動することで、

- 地域住民と会話する
- 地域の施設や場所を知る
- 地域で暮らす人と顔見知りになる
- 地域の生活を支える
- 地域の特徴や文化を知る

といった接点を自然につくることができます。

単に、

**「地方へ移住する」**

だけではなく、

**「地方へ移住した後、地域の人とつながる」**

ところまで支援することを目指します。

---

# 🏘️ 地域にとってのメリット

## 地域住民同士の交流が生まれる

YORIAIでは、地域の人が地域の人を乗せます。

そのため、単純な移動だけではなく、乗車中の会話などを通して地域住民同士が接点を持つ機会が生まれます。

公共交通では生まれにくい、地域の人同士の小さなつながりを増やすことを目指しています。

---

## 高齢者の孤立防止・見守り

移動手段がなくなることで、外出そのものが減ってしまう可能性があります。

移動手段を確保することは、買い物や通院だけではなく、

- 人と会う
- 地域施設へ行く
- 趣味を続ける
- 地域イベントへ参加する

といった社会との接点を維持することにもつながります。

また、地域のドライバーと定期的に接することで、将来的には日常的な見守りにつながる仕組みへの発展も想定しています。

---

## 既存の公共交通を補完する

YORIAIは、鉄道・バス・タクシーを置き換えることを目的としていません。

既存の交通だけでは対応しにくい移動を補完するサービスを目指しています。

例えば、

> 「駅までは遠いが、バスの本数も少ない」

といった地域で、自宅から駅や病院などへの移動をYORIAIが補助することで、既存の公共交通と組み合わせた移動が可能になります。

---

# 🔐 認証

認証には **Supabase Auth** を使用しています。

バックエンドAPIではアクセストークンを受け取り、

```text
Authorization: Bearer <access_token>
```

の形式で認証を行います。

これにより、ログインしているユーザーに応じて必要なデータへアクセスできる構成にしています。

---

# 🔌 API

バックエンドには **Next.js** を使用しています。

主なAPIとして、

```text
/api/login
/api/register
/api/users
/api/shift
```

などを実装しています。

## Login API

メールアドレスとパスワードを利用してログインします。

## Register API

ユーザー情報を受け取り、新しいユーザーを登録します。

主な登録情報：

- メールアドレス
- パスワード
- 氏名
- 電話番号
- 住所

## Users API

ログインユーザーに紐づく情報を取得します。

## Shift API

ドライバーの運行可能時間を管理します。

対応している処理：

- GET：シフト取得
- POST：シフト登録
- PATCH：シフト変更
- DELETE：シフト削除

同じ時間帯に重複したシフトが登録されないよう、重複チェックも行っています。

# 🗄️ データベース

データベースには **Supabase Database** を使用しています。

利用者・ドライバー・シフト・予約などの情報を管理する構成です。

予約情報では、例えば以下のようなデータを扱います。

```text
reservations

id
user_id
shift_id
status
passenger_count
start_address
start_latitude
start_longitude
end_address
end_latitude
end_longitude
desired_arrival_time
```

乗車地・目的地の住所だけでなく緯度・経度も保持できる構成とし、位置情報を利用した機能への拡張を想定しています。

# 🌱 プロジェクトについて

**YORIAI** という名前には、

> **地域の人が寄り合い、互いに支え合う**

という意味を込めています。

地方の移動問題を単なる交通インフラの問題として考えるのではなく、移動をきっかけに人と人がつながる。

高齢者が移動手段を失わない。

免許を返納しても生活を続けられる。

移住してきた人が地域の人と出会える。

外出することで、地域での交流や消費が生まれる。

そうした一つひとつのつながりから、地域そのものを活性化させることを目指しています。

> ## **乗り合う。つながる。地域が動く。**
